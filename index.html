Paragraphic

Parametric graphic design for Mac. Create complex 2D vector designs, patterns, and data-driven graphics using a modular system built for designers.

Modular Design System

Build intricate designs parametrically without code. Stack modules intuitively, leveraging familiar design conventions for precise control and rapid iteration.

Real-Time Experimentation

Adjust any step in your workflow instantly. See live updates to the final result—no undos or rebuilds required. Encourage bold exploration with confidence.

Seamless Workflow Integration

Export as crisp SVG vectors. Copy and paste directly into Figma, Sketch, or Illustrator to refine and scale within your existing tools.

Designer-First Interface

No coding barriers. A native macOS experience with refined panels, like the new Font Picker with filtering and recent fonts, optimized for focus and flow.

Performance and Precision

Swift rendering for gradients and complex shapes. Enhanced undo/redo grouping keeps your process fluid, even with data tables or color pickers open.


How It Works

1. Start with Modules

Select from shapes, paths, text, or data modules. Combine them modularly to form your base structure.

2. Parameterize and Tweak

Adjust variables like position, scale, color, or arcs in real-time. Changes propagate instantly across the design.

3. Preview and Refine

Experiment freely—edit early steps without disruption. Use utilities like the Font Picker or data editor for precision.

4. Export and Integrate

Copy SVG output. Paste into any vector app. Your parametric design becomes a native, editable asset.
